INSTALLER
---------
1. Ferme Ableton Live, puis double-clique sur Confluence-v@VERSION@-Windows-setup.exe.
2. Si Windows affiche « Windows a protégé votre ordinateur » (installeur non signé, voir BUILD-INFO.txt) :
   clique sur « Informations complémentaires », vérifie que le fichier est bien celui de la page officielle, puis
   « Exécuter quand même ». Ne désactive jamais l'antivirus pour installer un plugin.
3. Le plugin est copié dans C:\Program Files\Common Files\VST3\Confluence.vst3 (droits administrateur demandés).
4. Dans Ableton Live : Options > Settings (Préférences dans Live 11) > Plug-Ins, active « Use VST3 Plug-in System Folders », puis clique sur
   Rescan. Confluence apparaît dans le navigateur, dans Plug-Ins > VST3 > GRVTY Records.
5. Branchement vers ton synthé : voir ROUTAGE-ABLETON.md (2 pistes, « MIDI From »).

Configuration : Windows 10 ou 11 en 64 bits, Ableton Live 10.1 ou plus récent (ou un autre hôte VST 3 capable de
router la sortie MIDI d'un plugin vers une autre piste).

Vérifier le téléchargement : l'empreinte SHA-256 de l'installeur doit être identique à celle publiée dans
SHA256SUMS.txt (PowerShell : Get-FileHash Confluence-v@VERSION@-Windows-setup.exe). Télécharge Confluence uniquement
depuis la page officielle.


DÉSINSTALLER
------------
Paramètres > Applications > Applications installées > Confluence (VST3) > Désinstaller.
Tes presets personnels restent dans Documents\GRVTY Records\Confluence\Presets (supprime-les si tu veux).
