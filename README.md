# Plugins GRVTY Records

Plugins VST® 3 libres et gratuits pour Ableton Live (macOS et Windows), créations du label et collectif
**GRVTY Records**, développés par Jasperr.

| Plugin | Rôle |
|---|---|
| [Flow Filter](FlowFilter) | filtre en mouvement pour tes boucles techno |
| [Undertow](Undertow) | synthé FM avec séquenceur pour boucles techno hypnotiques |
| [Confluence](Confluence) | une note jouée devient un accord complet, envoyé en MIDI à ton synthé |
| [Ebb](Ebb) | sidechain et mise en forme du volume, courbe dessinée à la main |

Chaque dossier est un projet JUCE 8.0.12 / CMake autonome (voir son README).
Windows : `bash packaging/windows/build-windows.sh <Plugin>` (Git Bash, Visual Studio 2022+, CMake, NSIS 3),
ou automatiquement par GitHub Actions (`.github/workflows/windows.yml`).
