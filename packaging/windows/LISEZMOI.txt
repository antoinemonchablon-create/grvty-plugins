INSTALLER
---------
1. Ferme Ableton Live, puis double-clique sur @SETUP@.
2. Si Windows affiche « Windows a protégé votre ordinateur » (installeur non signé) :
   clique sur « Informations complémentaires », vérifie que le fichier vient bien de GRVTY Records, puis
   « Exécuter quand même ». Ne désactive jamais l'antivirus pour installer un plugin.
3. Le plugin est copié dans C:\Program Files\Common Files\VST3\@PRODUCT@.vst3 (droits administrateur demandés).
4. Dans Ableton Live : Options > Settings (Préférences dans Live 11) > Plug-Ins, active « Use VST3 Plug-in
   System Folders », puis clique sur Rescan. @PRODUCT@ apparaît dans Plug-Ins > VST3 > GRVTY Records.

Configuration : Windows 10 ou 11 en 64 bits, Ableton Live 10.1 ou plus récent (ou un autre hôte VST 3).
Vérifier le téléchargement : l'empreinte SHA-256 de l'installeur (PowerShell : Get-FileHash @SETUP@)
doit être identique à celle de SHA256SUMS-Windows.txt.


DÉSINSTALLER
------------
Paramètres > Applications > Applications installées > @PRODUCT@ (VST3) > Désinstaller.
Tes presets personnels restent dans Documents\GRVTY Records\@PRODUCT@ (supprime-les si tu veux).
